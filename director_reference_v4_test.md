## SOURCE-DERIVED FILMMAKING PATTERNS
- MULTI-SUBJECT COVERAGE: recurring frames contain two or more people; study how attention shifts between subjects.
- SUBJECT–OBJECT EMPHASIS: recurring frames move attention between people and handled/looked-at objects.
- FREQUENT VISUAL CHANGE: sampled composition/content changes often across the timeline; candidate for active coverage or frequent shot changes.
- BLOCKING VARIATION: subjects appear in different body positions/staging states across the sequence.
- LOCATION CONTEXT: environment is repeatedly readable around subjects rather than disappearing from coverage.

## OBSERVED SEQUENCE PATTERNS
- DETAIL / INFORMATION → ACTION / PHYSICAL
- ACTION / PHYSICAL → DETAIL / INFORMATION
- DETAIL / INFORMATION → CHARACTER / PERFORMANCE
- CHARACTER / PERFORMANCE → ACTION / PHYSICAL
- ACTION / PHYSICAL → CHARACTER / PERFORMANCE
- CHARACTER / PERFORMANCE → DETAIL / INFORMATION

## 🟡 CANDIDATE DIRECTING RULES — TESTING
- When multiple subjects share a scene, keep their relationship readable and make attention shifts purposeful.
- When an object becomes important, establish the subject/object relationship before shifting emphasis, then preserve the object clearly through the beat.
- For visually active sequences, allow purposeful coverage changes when subject, information, action, or reaction changes; avoid arbitrary changes.
- Let blocking evolve through readable staging changes while preserving where subjects are relative to each other and the environment.
- Re-establish enough environmental context during coverage so scene geography remains readable.

## SOURCE SEPARATION
These rules are generalized from detected filmmaking patterns, not source-specific characters, dialogue, locations, props, or exact shot sequences.
